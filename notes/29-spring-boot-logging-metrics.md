# Spring Boot Logging & Metrics

## Introduction

Logging and metrics are essential for understanding an application's behavior and performance.

They help with:

- Monitoring applications
- Troubleshooting issues
- Diagnosing problems
- Understanding application performance
- Optimizing application behavior

## Logging vs Metrics

| Logging | Metrics |
|---|---|
| Records events, actions, and information | Measures application/system behavior |
| Useful for troubleshooting and auditing | Useful for monitoring and performance analysis |
| Provides detailed information about what happened | Provides quantitative measurements |

### Quick Recall

> **Logging tells us what happened. Metrics tell us how the application is performing.**

---

## 2. Logging Fundamentals

**Logging** is the process of recording events, actions, and information generated by an application.

Logs are useful for:

- Monitoring application behavior
- Troubleshooting problems
- Auditing application activity
- Understanding what happened during application execution

### Common Logging Concepts

- **Log Level** → indicates the severity or importance of a logged event.
- **Log Message** → the information recorded in the log.
- **Log Pattern** → defines how log information is formatted and displayed.

Common logging frameworks and APIs used in Java applications include:

- **SLF4J**
- **Logback**
- **Log4j2**

---

## Logging Levels

Logging levels indicate the **severity of an event**.

From highest severity to lowest:

```text
ERROR
  ↓
WARN
  ↓
INFO
  ↓
DEBUG
  ↓
TRACE
```

### ERROR

Indicates a serious problem or failure that may prevent an operation from completing successfully.

### WARN

Indicates a potentially problematic situation that does not necessarily stop the application.

### INFO

Provides general information about the normal operation of the application.

### DEBUG

Provides detailed information useful for debugging and understanding application behavior during development.

### TRACE

Provides the most detailed level of logging information and is useful when very fine-grained execution details are required.

> **Quick Recall:**
>
> `ERROR → WARN → INFO → DEBUG → TRACE`
>
> Higher level → greater severity  
> Lower level → more detailed information

## Spring Boot Logging with SLF4J

Spring Boot applications can use **SLF4J** to create and work with loggers.

A logger can be created using `LoggerFactory`:

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

public class SampleClass {

    private static final Logger logger =
        LoggerFactory.getLogger(SampleClass.class);

    public void performActions() {
        logger.debug("This is a debug message.");
        logger.info("This is an info message.");
        logger.warn("This is a warning message.");
        logger.error("This is an error message.");
    }
}
```

### Understanding the Implementation

**`Logger`**

Represents the logger used to write log messages.

**`LoggerFactory`**

Creates a logger for the specified class.

```java
LoggerFactory.getLogger(SampleClass.class);
```

**Logging methods**

```text
logger.debug() → Debug information

logger.info()  → General application information

logger.warn()  → Warning information

logger.error() → Error information
```

> **Quick Recall:**
>
> `LoggerFactory` → creates the logger  
> `Logger` → records log messages  
> `debug / info / warn / error` → log at different levels
