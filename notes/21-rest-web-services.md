# REST Web Services

## Overview

This note introduces web services, REST architecture, HTTP methods, REST APIs, and their implementation using Spring Boot.

---

## XML vs JSON

### XML

- Markup language
- Tree-like structure
- Verbose
- Traditionally used with SOAP

### JSON

- Lightweight data-interchange format
- Uses key-value pairs
- Easy for humans and machines to read
- Widely used in REST APIs

---

## SOAP vs REST

### SOAP

- Protocol
- Uses XML messages
- Supports multiple transport protocols (HTTP, SMTP, etc.)
- More rigid and standardized

### REST

- Architectural style
- Primarily uses HTTP
- Commonly uses JSON (can also use XML)
- Lightweight and widely used in modern web applications
