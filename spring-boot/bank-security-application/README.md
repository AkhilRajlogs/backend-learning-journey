# Bank Security Application

A Spring Boot backend application that simulates core banking operations including account management, card allocation, investments, KYC verification, and role-based access control.

## Tech Stack

- Java 17
- Spring Boot 2.7.16
- Spring Security
- JWT Authentication
- Spring Data JPA
- MySQL
- Maven
- Lombok

## Current Features

### Completed

- Banking Domain Enums
- Banking Domain Entities
- DTO Layer
- Repository Layer
- JWT Authentication Models
- Custom User Details Service
- Project Documentation and Progress Tracking

### In Progress

- Spring Security Configuration
- JWT Authentication Flow

### Planned

- Service Layer
- User Registration
- Login
- Account Management
- Card Management
- Investment Management
- Admin Operations
- Global Exception Handling
